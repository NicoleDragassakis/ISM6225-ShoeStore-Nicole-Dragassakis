About this project

Sole & Co. was developed for ISM 6225 Assignment 1: Look and Feel. The purpose of the website is to combine a premium storefront experience with practical business application concepts, including inventory management, front-end interactivity, and simple analytics dashboards.

I wanted the experience to feel like a real retail brand: polished, organized, and data-aware, but still simple enough to run on GitHub Pages with no backend.

The website was constructed using HTML for structure, CSS for visual design and responsive layout, and JavaScript for dynamic interaction. Product data is stored in a shared JavaScript source and persisted in browser localStorage to simulate inventory changes without needing a server.

Chart.js is used for the analytics view, GitHub is used for version control, and GitHub Pages hosts the completed site.
